# RIZ by Shijiriju E-Commerce Project

A production-ready e-commerce platform featuring a Next.js 15 frontend and an Express.js / Prisma backend.

## Project Structure
- `project/`: Next.js 15 frontend application.
- `backend/`: Express.js backend API and Prisma schema definitions.
- `.gitignore`: Root-level Git exclusion settings.
- `.env.example`: Template for environment configuration files.
